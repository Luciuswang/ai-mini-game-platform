# 🚀 多人在线射击游戏

一个完整的实时多人在线射击游戏，支持4人同时竞技，包含AI机器人、宝箱系统、Boss敌机和实时积分排行榜。**已优化移动端体验，完美支持手机游戏！**

## 🎮 游戏特色

- ✈️ **多人实时对战** - 最多4个玩家同时游戏
- 🤖 **智能AI填充** - 自动添加AI机器人，无需等待
- 🎁 **宝箱奖励系统** - 收集不同类型的宝箱获得奖励
- 👾 **多种敌机** - 普通敌机和Boss敌机
- 🏆 **实时排行榜** - 屏幕顶部显示实时分数
- 🎨 **多色战机** - 每个玩家不同颜色的战斗机
- 💥 **炫酷特效** - 爆炸粒子和战斗特效

## 🚀 快速开始

### 本地运行

1. 克隆仓库
```bash
git clone <仓库地址>
cd shooter-multiplayer
```

2. 安装依赖
```bash
npm install
```

3. 启动服务器
```bash
npm start
```

4. 访问游戏
```
http://localhost:5000
```

## 🎯 游戏玩法

1. **创建/加入房间** - 点击按钮进入游戏房间
2. **等待玩家** - AI机器人会自动填充到4人
3. **准备开始** - 所有玩家准备后自动开始
4. **控制战机** - 鼠标移动控制飞机位置
5. **自动射击** - 飞机会自动连续射击
6. **收集宝箱** - 飞过宝箱可获得奖励：
   - 💚 **生命宝箱** - 恢复生命值
   - 💰 **金币宝箱** - 额外分数
   - ⚡ **速度宝箱** - 提升移动速度
   - 🔫 **武器宝箱** - 增强火力
7. **击败敌机** - 消灭敌机获得分数
8. **排行竞争** - 60秒内获得最高分获胜

## 🛠 技术栈

- **前端**: HTML5 Canvas, CSS3, JavaScript ES6+
- **后端**: Node.js, Express, Socket.IO
- **部署**: Render, Railway, Vercel
- **实时通信**: WebSocket

## 📱 支持平台

- 🖥️ **桌面浏览器** - Chrome, Firefox, Safari, Edge
- 📱 **移动设备** - 响应式设计，支持触摸控制
- 🌐 **跨平台** - 任何支持现代浏览器的设备

## 🎨 自定义配置

### 游戏设置
- 游戏时长: 60秒（可修改）
- 最大玩家: 4人
- AI机器人: 自动填充
- 难度级别: 可调整

### 宝箱类型
- `health`: 生命值恢复
- `score`: 额外分数
- `speed`: 移动速度提升
- `weapon`: 武器强化

## 🚀 部署到免费服务器

### Render部署
1. Fork这个仓库
2. 注册 [Render](https://render.com)
3. 连接GitHub仓库
4. 设置构建命令: `npm install`
5. 设置启动命令: `npm start`
6. 部署完成！

### Railway部署
1. 注册 [Railway](https://railway.app)
2. 连接GitHub仓库
3. 自动检测Node.js项目
4. 一键部署完成！

### Vercel部署（仅静态前端）
1. 注册 [Vercel](https://vercel.com)
2. 导入GitHub仓库
3. 自动部署HTML文件
4. 需要配置后端API
